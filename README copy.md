## 🚀 Getting Started

```bash
git clone https://github.com/aradhy404/Backend-Project.git
cd Backend-Project
npm install
npm run dev
```

### Environment Variables

Create a `.env` file and add your own values:

```env
PORT=8000
MONGODB_URI=your_mongodb_connection_string
```

**Never commit `.env` or expose credentials.**
